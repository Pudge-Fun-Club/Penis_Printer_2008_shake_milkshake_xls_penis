# Конспекты на Ender-3 Neo

Принтер проверен по USB: **Creality Ender-3 Neo**, Marlin **2.0.8.2**,
**115200** бод. Перепрошивать его для письма не нужно: X/Y перемещают ручку,
Z поднимает и опускает её. Нагрев и подача пластика при письме не используются.

## Запуск

Из этой папки:

```bash
./scripts/run-notes.sh
```

Открой <http://127.0.0.1:8010>. Этот запуск предназначен для одного пользователя
на этом компьютере, без формы входа, и слушает только локальный адрес.
Данные, ключ и калибровка хранятся в `data/`; эта папка исключена из Git.

Один раз установи постоянный доступ к USB-интерфейсу принтера:

```bash
sudo ./scripts/install-printer-access.sh
```

Скрипт устанавливает правило udev для CH340-интерфейса этого принтера и сразу
применяет его к подключённому устройству. Номер `ttyUSB` может меняться после
перезапуска; постоянное USB-имя и доступ сохраняются. Разовое `setfacl` на
`/dev/ttyUSB0` этого не обеспечивает.

В простое приложение проверяет связь запросом температуры `M105` каждые три
секунды, без движения и изменения нагрева. После потери связи оно повторяет
подключение автоматически. Прерванная запись останавливается, прежние координаты
сбрасываются; поиск нуля и продолжение записи автоматически не выполняются.
При смене USB-адаптера задай новый порт при запуске:
`PRINTER_SERIAL_PORT=/dev/serial/by-id/новый-порт ./scripts/run-notes.sh`.

## Ручка

На принтере пока обычная головка. Нужно физически установить ручку, которая
выступает ниже сопла, и закрепить бумагу. Изготовить и установить крепление
удалённо невозможно.

В `media/models/` лежат готовые `pen-holder-9mm.stl` и `pen-holder-11mm.stl`,
а также параметрический `pen-holder.scad`. Это универсальный зажим под стяжки,
**прототип без измеренной посадки на твою головку**. Проверь диаметр ручки,
место крепления и свободный ход до установки; модель не является проверенным
штатным креплением Ender-3 Neo. Пластиковую деталь нужно распечатать обычным
слайсером до установки ручки. Повторная генерация под другой диаметр:

```bash
uv run python scripts/make-pen-holder.py --diameter 10
```

Крепи к неподвижной части каретки, не к лопастям вентилятора, проводам или
CR Touch. Лучше шариковая ручка с мягким креплением: усилие небольшое, кончик
при письме только касается листа. Сопло и стол должны остыть до комнатной
температуры. Следи, чтобы зажим и ручка не цепляли датчик, ремень и клипсы.

## Первая калибровка

1. **Сними ручку**, освободи стол. Открой `Control`, выполни `Home`.
   Ender-3 Neo ищет Z через CR Touch в центре стола; приложение теперь читает
   реальные координаты после homing через `M114`, а не считает их нулевыми.
2. Подними Z, затем закрепи ручку так, чтобы кончик оказался ниже сопла.
   При установленной ручке не выполняй повторный `Home`: она может удариться
   о стол. После отключения USB сними ручку и повтори поиск нуля.
3. Закрепи бумагу малярной лентой вне рабочего участка. Нажми
   «Настроить ручку и бумагу», чтобы открыть мастер `Paper`.
4. Перемещай поднятую ручку к двум противоположным углам доступного участка
   бумаги. Запиши нижний левый и верхний правый углы (`BL` / `TR`). Примени
   отступ, например 5 мм. Для калибровки ориентируйся на **кончик ручки**,
   поскольку он смещён относительно сопла.
5. Над бумагой опускай Z небольшими шагами, у поверхности — по 0,1 мм.
   В момент лёгкого касания сохрани `Pen down` через захват текущей позиции.
   Подними Z на 2–3 мм и сохрани `Pen up`. Не вводи придуманные высоты.
6. Для первой пробы вставь короткое слово «Привет», поставь высоту букв 5 мм,
   посмотри предпросмотр и запусти один лист. Если ручка давит или не пишет,
   останови запись и поправь высоту.

Приложение не разрешает запуск конспектов без известной позиции, калибровки
ручки и бумаги; не выполняет автоматический `G28` при запуске этих заданий.
Перед записью повторно проверяет границы и совпадение профиля.

Рабочий ход Ender-3 Neo — 220 × 220 мм. A4 имеет длину 297 мм: лист можно
закрепить с выступающим краем, но писать получится только на откалиброванном
участке. Длинный текст автоматически делится на несколько таких листов.
Размер участка указан над предпросмотром; страницы не уменьшаются до нечитаемого
размера ради размещения на одном листе.

## Фото и почерк

На вкладке **Конспекты** выбери или перетащи PNG/JPEG/WebP до 15 МБ, оставь
почерк **Как на фото** и нажми **Сделать SVG**. Вся страница трассируется в
настоящие векторные штрихи: буквы, формулы, рисунки, таблицы и схемы сохраняют
своё расположение. Светлая клетка и линейки тетради удаляются перед трассировкой;
тёмные штрихи ручки на пересечениях сохраняются. Этот режим работает локально,
без OCR и без API-ключа.
Сними страницу прямо сверху при хорошем свете. Выравнивание по краям выключено
по умолчанию: большая рамка рисунка иногда принимается за границу страницы.
Если включишь его для снимка под углом, проверь, что в SVG ничего не обрезалось.

Справа показан SVG, который можно скачать и проверить перед записью. Для
печати SVG сохраняется отдельным файлом, читается векторным парсером и
переводится в G-code; растр не вкладывается в SVG вместо векторизации.
Страница целиком вписывается в рабочий участок с сохранением пропорций.
Порядок штрихов оптимизируется автоматически: связанные части рисуются вместе,
а отдельные элементы обходятся по короткому маршруту с выбором направления.
Повторные проходы допускаются только по уже существующим линиям и выбираются,
если они быстрее подъёмов ручки при текущих скоростях. Лишние вершины удаляются
с допуском 0,02 мм; точки и отдельные элементы не соединяются перемычками.
Этот порядок сохраняется в скачанном SVG и в G-code.
Растровая трассировка зависит от качества фото: тени и очень мелкие точки могут
влиять на результат, поэтому нужен предпросмотр.

Для смены почерка выбери один из трёх русских вариантов. Он выделяет текстовые
строки, меняет только их штрихи и сохраняет остальную графику. Формулы и рисунки
модель должна оставлять в исходном виде. Проверь границы замены в предпросмотре:
ошибочно выделенная область может задеть соседние элементы.

Этот дополнительный режим требует OpenAI API-ключа: открой «Настройки
распознавания» и сохрани его локально. Ключ не возвращается браузеру, фото
отправляется провайдеру только при замене почерка. Можно задать `OPENAI_API_KEY`
или `OCR_API_KEY`, модель — `OCR_MODEL` (по умолчанию `gpt-4.1-mini`), адрес
совместимого сервера — `OCR_BASE_URL`. Реальное выделение текста ещё нужно
проверить на твоих фотографиях с ключом; автоматические проверки используют
контролируемые ответы провайдера.

Три встроенных почерка — **Аккуратный**, **Наклонный**, **Живой** — поддерживают
весь русский алфавит, латиницу и числа. Они используют настоящие одиночные
штрихи; «Живой» добавляет небольшие воспроизводимые вариации букв. Это стилизация,
а не копирование почерка конкретного человека. Свой почерк можно записать в
`Font Editor` или импортировать `.gcsfont`. Для него должны быть записаны все
нужные символы. При отсутствии символа приложение остановит генерацию с
понятной ошибкой, вместо пропуска буквы.

Для фото подтверди закрепление чистого листа и нажми **Написать SVG**. Для
обычного набранного текста доступна кнопка **Ввести текст вручную**; этот режим
автоматически переносит строки и разбивает длинный конспект на листы. Каждый
следующий лист запускается отдельно после завершения текущего и замены бумаги.
