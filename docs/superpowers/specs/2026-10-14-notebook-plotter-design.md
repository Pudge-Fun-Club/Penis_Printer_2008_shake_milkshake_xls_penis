# Конспекты на Ender-3 Neo

Пользователь хочет загрузить фото конспекта, выбрать почерк и переписать текст
ручкой на бумагу. Принтер идентифицирован через M115: Creality Ender-3 Neo,
Marlin 2.0.8.2, USB 115200. Сейчас установлена печатающая головка; ручки нет.

Уточнение пользователя: главным промежуточным документом должен быть **SVG всей
страницы**, сохраняющий не только буквы, но и рисунки, формулы и схемы. Главный
экран теперь фото → SVG → ручка. Режим «Как на фото» трассирует реальные штрихи
локально без OCR. Замена почерка выделяет лишь текстовые строки; остальные
штрихи сохраняются. SVG можно скачать; генератор G-code действительно читает
сохранённый SVG. Старое предложение описывать рисунки текстом отменено.

Развиваем существующий FastAPI/React проект. Основной экран на русском:
фото → распознанный редактируемый текст → почерк → предпросмотр листов → запись
выбранного листа. Текст также можно вставить вручную. При смене почерка фото отправляется в OpenAI
Responses API только после действия пользователя; ключ сохраняется локально
через защищённый API и не возвращается браузеру. Модель настраивается, исходный
выбор разработчика — gpt-4.1-mini. Без ключа работает точная трассировка;
замена почерка честно недоступна. Пользователь проверяет заменённые области.

Почерки должны поддерживать кириллицу. Неизвестные символы нельзя молча удалять.
Перенос строк учитывает реальные размеры штрихов. Длинный текст делится на
листы размером с откалиброванный рабочий участок; A4 целиком может не помещаться
в ход принтера. Следующий лист запускается вручную после замены бумаги.

Генерация использует существующий save_scene_job, проверки G-code и отпечаток
профиля. Перед записью проверяются бумага, высота ручки, известная позиция,
подключение и отсутствие активной работы. Задания конспектов не выполняют
автоматический G28: ручка выступает ниже сопла и должна устанавливаться после
поиска нуля. Нагрев не используется, экструзии нет. До физической установки
ручки и калибровки реального письма не будет.

Подготовить параметрический держатель для крепления стяжками и понятные
инструкции установки; размеры ручки и место крепления проверяет пользователь.
Программно собрать, проверить и запустить локальное приложение.
